New here? How to read this

The model projects every player and game from recent form, then compares its own number with the price the book is offering. It only shows you a bet when it thinks the book is wrong by enough to matter.

  • Model % — how often the model thinks this hits.
  • Book % — how often the price says it hits, with the bookmaker's cut removed.
  • Edge — the gap between them. Bigger is better; anything here has already cleared the model's minimum.
  • Suggested stake — a deliberately cautious fraction of the bankroll you set, sized to the edge.

An edge is a long-run average across many bets, not a prediction about this one. Most of these lose.

Longshots pay big because they rarely hit. These are the likeliest routes to that payout, not likely ones — and the model still shows you what each is worth in the long run, which for a big parlay is usually negative. Bet accordingly.
